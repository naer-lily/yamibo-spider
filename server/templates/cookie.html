配置 Cookie

需要从已登录的浏览器中获取 Yamibo 论坛 Cookie。以下三种方式任选其一：

在 Yamibo 网站的 Console 中运行以下代码

先登录 bbs.yamibo.com，然后按 F12 打开开发者工具，切换到 Console 标签，粘贴以下代码并回车：

copy(JSON.stringify(
  document.cookie.split('; ').map(c => {
    const eq = c.indexOf('=');
    return { name: c.slice(0, eq), value: c.slice(eq + 1) };
  })
));
console.log('Cookie 已复制到剪贴板！回到管理页面粘贴。');

从浏览器 DevTools 复制 Cookie 字符串

在 Yamibo 网站任意页面地址栏前点击锁图标 → Cookie → 选择任一项 → 复制 "Cookie" 请求头值。或者：F12 → Application → Cookies → 导出时会得到类似的字符串。
