配置 Cookie

Discuz! X3.5 的关键认证 Cookie（_auth、_saltkey）是 HttpOnly 的，JS 拿不到。推荐以下两种方式获取：

从浏览器 DevTools Application 面板导出

  1. 在 Chrome 中登录 bbs.yamibo.com
  2. 按 F12 打开 DevTools → Application 标签 → Cookies → 点击 bbs.yamibo.com
  3. 在 Console 中粘贴以下脚本并回车，会自动导出全部 Cookie（包括 HttpOnly）为 JSON：
// 在 Application → Cookies 面板打开后运行
copy(JSON.stringify(await (new Promise((resolve) => {
  chrome.devtools.inspectedWindow.eval(
    'document.cookie',
    (result) => resolve(result)
  );
}))));

⚠️ 如果以上脚本不可用，请使用 EditThisCookie 浏览器扩展导出，或者在 Application 面板中逐个截图， 然后在下方 JSON 区域手动填写关键 Cookie 值：


或使用 Playwright 登录（最完整）

在宿主机运行以下命令，会自动生成 cookies.json：

cd yamibo-spider && python -m server.yamibo.auth

然后将生成的 cookies.json 放到项目根目录（Docker 则挂载到 /app/cookies.json）。
